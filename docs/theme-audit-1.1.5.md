# 1.1.5 日夜主題修正

## 問題與結果

便利貼輸入視窗的預設按鈕樣式曾蓋過停用樣式，造成深色背景上的字難以辨識。
改為只對啟用的預設／主要按鈕套用強調色，並明確處理停用、滑過與按下狀態。

遍歷應用程式 Python、QSS、SVG 來源，檢查固定色碼、具名色、QColor、前景／背景筆刷、內嵌 HTML、圖示及繪製覆蓋層：

- 提示文字、依賴檢查、無障礙狀態、附件、字型、預檢、文件歸檔及低信心度標示改用共同語意色。
- 表格／樹狀項目保留語意資料，切換時重建筆刷，包含隱藏視窗與巢狀項目。
- 比較結果與註解摘要在開著的視窗即時更新；PDF 中的特殊字元在比較文字中正確跳脫。
- 分頁關閉、輸入框清除、勾選、下拉與數值調整箭頭改用主題圖示。
- 進度條文字在填滿及未填滿區域都保持對比。
- 選取、測量、格線、編輯工具與簡報頁碼使用共同色盤；測量／頁碼文字有明確背景。
- 完成 Qt 色盤的全部可見角色，移除兩份未使用、含固定色碼的舊 QSS。

顏色值集中在 `ui/theme.py`；`ui/theme_roles.py` 提供語意筆刷與控制項圖示。
主題圖示生成在系統暫存目錄，避免對安裝位置或當前工作目錄要求寫入權限。
程式標誌、PDF 內容、頁面背景色選擇及實際註解墨色屬於文件／品牌資料，保留原色；墨色預覽與輸出的墨色一致。
列印／匯出的註解摘要採明確的淺色紙面色盤，不把深色閱讀配色印到紙上。

## 驗證

`tests/test_theme_controls.py` 進行實際按鈕像素對比、兩次日夜來回、動態狀態、巢狀項目筆刷、HTML、圖示及來源防回歸檢查。
兩種主題的主要、一般、提示、停用及警告色組合均要求至少 4.5:1；40 次按鈕狀態繪製請求最低 5.08:1。
`--verify-window-geometry REPORT.json` 在安裝包中同時測試 96 次視窗移動／調整、192 次小型圖示請求及主題控制項，使用生成的文件與隔離設定。
Cocoa 對自動驗證視窗可能抑制游標滑過外觀；僅接受共同色盤中的一般／滑過背景，並檢查實際繪製字色及對比。離屏回歸測試要求每個指定狀態的精確背景。
Windows 發布流程必須通過安裝後的相同驗證，才可上傳檔案。

測試不等同於 Apple 公證、Windows 簽章、螢幕閱讀器或實體列印認證；既有預覽限制仍適用。
